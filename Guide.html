Part 1: One-Time Claude Setup

Transform Claude into a non-technical automated deployment concierge by setting up a dedicated workspace.

1

Create a Claude Project

Log in to Claude.ai (Pro required). Click on Projects in the left sidebar, and click Create Project. Name it "Airwallex Site Cloner".

2

Upload the Brain Files

Inside your new Project, look for the Project Knowledge section. Upload these specific files from the /skill folder in this package:

  • themes.json (Design systems)
  • setup.js (Policy injection script)
  • Dockerfile (Dokploy config)
3

Configure Custom Instructions

Open the SKILL.md file from the /skill folder in a text editor. Copy all the text and paste it into the Custom Instructions box in Claude.

Part 2: Generating a Site

How to use Claude when signing a new client or launching a new domain.

1. The Interview

Open your Claude Project and start a new chat with:

I need to spin up a new site. Start the interview.

Claude will ask for the Company Name, Registration, Address, Niche, Theme, and Domain in plain English.

2. Execute the Magic Script

Once you answer the questions, Claude will quietly write the copy, find images, and prepare the deployment. It will then give you a single "magic" script to run. It will not burden you with technical explanations.

Open your Terminal (or Command Prompt), ensure you are in the directory where you extracted this zip, and paste the command!

This script will automatically copy the files, inject your details, upload to GitHub, and trigger the Dokploy server using the built-in API.

3. Point Your Domain

The script handles the deployment. The only manual step left is logging into Cloudflare and pointing your domain to the server:

Type: A
Name: @
Content: [Your Dokploy Server IP]
Proxy: On (Orange Cloud)

You're Done!
